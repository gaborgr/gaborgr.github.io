How I build

Coding agents, used the way a lead uses a team

Sixteen products in twelve months next to a full-time job only works with agents in the loop. It works because of how I use them, not because they write code while I look away.

01Plan first

Architecture, scope and data model are decided before a single line is generated. The agent implements a plan, it does not invent one.

02Small diffs

One change at a time, reviewed line by line. A diff I cannot explain does not get merged, no matter how well it runs.

03I own the result

If it breaks in production it is mine. I read what ships, I debug it myself and I can defend every decision in a review.

04In production, not just in my editor

The Claude API runs inside Hallazgo's publishing pipeline, MCP servers and headless automation handle the repetitive parts, and CI on EAS and Vercel ships the rest.
